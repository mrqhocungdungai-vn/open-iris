Plugins

  
~/.open-iris/plugins/<tên>/. Plugin mới cài đều tắt. Bật/tắt và chu kỳ có hiệu lực từ lần Bắt đầu kế tiếp; các ô nhập dùng ngay.

  

  

  
 

  
 

  

  

  
Chọn một thư mục (một plugin hoặc cả repo), hoặc dán link GitHub của repo hay của một thư mục plugin (…/tree/<nhánh>/plugins/<tên>). Iris liệt kê các plugin tìm thấy; tick plugin muốn chép vào ~/.open-iris/plugins/. Plugin mới cài đều tắt. Cập nhật: thêm lại thư mục hoặc link đó (phải tin cậy lại).

Tin cậy plugin này? 

    
Plugin sẽ chạy các lệnh sau trên máy bạn:

    
    
    
    Plugin nhận nguyên văn lời bạn và Iris nói trong mỗi lượt. Lệnh có thể lưu hoặc gửi nội dung đó đi nơi khác.
    
    
    Lệnh chạy với quyền của bạn và không bị sandbox: chúng đọc, ghi được file của bạn. Chỉ tin cậy plugin bạn biết rõ nguồn. Plugin đổi bất kỳ file nào thì Iris sẽ hỏi lại.
    
     
  
    
    


  
    
  
    
    
    Chào mừng đến Iris
    
    
    Iris điều khiển máy Mac bằng giọng nói và bàn tay.
    
    
    Vài bước kiểm tra trước khi dùng, khoảng 2 phút. Bước nào chưa xong thì tính năng đó tạm khoá, bạn vẫn dùng được phần còn lại.
    
  
    
  
    
    
    1. Gemini API key
    
    
    Giọng nói chạy bằng Gemini Live. Key lưu trong ~/.open-iris/.env, chỉ gửi tới Google.
    
    
    
     
    
    Chưa có key? Lấy miễn phí tại aistudio.google.com/apikey. Bỏ qua được: khi đó chỉ dùng bàn tay.
